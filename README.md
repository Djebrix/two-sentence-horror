A horror story of exactly two sentences, written for the [Two-Sentence Horror bounty](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253).

`main.py` (stdlib only, no network) writes the story to `entry.txt`:

> The man downstairs leaves a pair of small shoes outside his door every night, though he lives alone. This morning there were two pairs — and one of them was mine, still warm.

Run it with `ENTRY_OUTPUT_DIR` set to choose where `entry.txt` lands:

```sh
ENTRY_OUTPUT_DIR=/tmp/out python3 main.py
```
